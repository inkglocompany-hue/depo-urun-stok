# NFC Depo Ürün Stok Demo

Fuar sunumu için hazırlanmış mobil uyumlu NFC stok/depo yönetim demosudur.

## Özellikler
- Ürün listesi ve stok durumu
- Ürün arama
- Stok girişi / çıkışı
- Stok hareket geçmişi
- Yeni ürün ekleme
- Az stok göstergesi
- Telefon ekranına uygun arayüz
- Verilerin tarayıcı localStorage alanında saklanması
- NFC etiketiyle ürün ekranına yönlendirme için ?product=ÜRÜN_ID desteği

Örnek: https://alanadiniz.com/?product=1

Bu sürüm fuar demosudur. Gerçek çok kullanıcılı depo sistemi için sunucu taraflı veritabanı ve kullanıcı yetkilendirmesi eklenmelidir.
